# Elders Group — Professional Multi-page Corporate Website

A premium, responsive multi-page website for Elders Group of Companies, built with Next.js App Router, React and TypeScript. Real company photographs and logos live in `public/images/` and `public/logos/`.

## Technology
- Next.js 15 App Router + React 19 + TypeScript
- Tailwind CSS 4 with custom corporate styling in `app/globals.css`
- Framer Motion for subtle reveal animations
- Lucide React icons
- Supabase dependencies staged for the planned CMS/backend phase

## Run locally
```bash
npm install
npm run dev
```
Open http://localhost:3000.

For a production build:
```bash
npm run typecheck
npm run build
npm start
```

## Pages included
- `/` — Homepage
- `/about` — Company story, mission, vision, core values and leadership team
- `/businesses` — Six-business directory
- `/businesses/[slug]` — Dynamic detail pages for each of the six subsidiaries:
  - `travels-tours`, `outsourcing-consulting`, `travel-business-school`,
    `hospitality`, `security-services`, `goodness-impact-foundation`
- `/projects` — Project portfolio starter
- `/impact` — Foundation and five thematic areas
- `/news` — News and insights content space
- `/contact` — Contact details, enquiry form and map
- `/partner` — Partnership opportunities
- `/privacy` and `/terms` — Legal pages
- `/sitemap.xml` and `/robots.txt` — generated by `app/sitemap.ts` and `app/robots.ts`

## Editing content
Business profiles, leadership information and values are centralised in `lib/data.ts`. Brand contact details (email, phone numbers, address) are in the `CONTACT` constant in `lib/data.ts`; social profile URLs are in the `SOCIAL` constant.

## Enquiry form delivery
`components/ContactForm.tsx` supports two submission modes, selected via the `SUBMISSION_MODE` constant:
1. `mailto` (current default) — opens the visitor's email client with the enquiry pre-filled to the company address. Works with zero configuration.
2. `formspree` — POSTs to a real form endpoint. Set `FORM_ENDPOINT` (e.g. a Formspree form ID) and switch `SUBMISSION_MODE` to `formspree` to enable online lead capture with mailto fallback.

## Original assets
Original unoptimised photographs are kept in `reference/original-images/`. Production hero images are optimised WebP versions in `public/images/hero/`.

2. Confirm legal names and official descriptions for each subsidiary.
3. Verify leadership names, qualifications and designations.
4. Replace starter project entries with verified projects, captions, dates and outcomes.
5. Connect the enquiry form by configuring `SUBMISSION_MODE` and `FORM_ENDPOINT` in `components/ContactForm.tsx` (Formspree, Resend, or a custom server-side endpoint with validation, spam protection and email delivery). The form does not perform live lead processing until this is done.
6. Update the placeholder social profile URLs in the `SOCIAL` constant in `lib/data.ts` with the official Facebook, Instagram and LinkedIn profiles.
7. Add a privacy notice and any required cookie/analytics disclosures.
8. Configure Supabase only when the CMS/admin phase begins; enforce server-side authentication, role permissions and storage policies.
9. Test accessibility, mobile layouts, metadata, performance and all forms before deployment.

## Deployment
The project is structured for Vercel deployment. Connect the repository to Vercel, configure the production environment, test the preview deployment, then point `eldersgroup.com.ng` to the approved production deployment after the replacement site is signed off.

## Scope note
This delivery is a multi-page frontend website foundation. It includes the public-facing pages and placeholder content. A production CMS, secure admin dashboard, database-backed enquiry handling, email notifications and live social integrations are separate backend tasks and are not represented as completed functionality.
